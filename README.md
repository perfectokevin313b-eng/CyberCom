# CyberCom Protect — publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta, conservando la carpeta assets.
3. En Settings → Pages, elige Deploy from a branch, rama main y carpeta /(root).
4. Guarda y espera la URL pública que proporciona GitHub Pages.

index.html es la página inicial. Conserva assets/cybercom-logo.png, assets/app-dashboard.png y CyberCom_Console_Demo.html en estas rutas. La consola Luna & Lino es un ejemplo ficticio; no se conecta a tienda, aseguradora ni método de pago. Precios, cálculos y coberturas son ilustrativos.


## Demo de tienda en la consola
La consola CyberCom incluye una pestaña Tienda Brinco que carga la página ficticia incluida en la ruta brinco/index.html. Conserva esa carpeta al publicar para que la tienda aparezca dentro del demo. Catálogo, bolsa, chatbot y pedidos son demostrativos; no se realizan ventas.
